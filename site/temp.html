Paragraphs and inline text

A paragraph is a <p>. Inside it, strong marks importance and em marks stress, while b and i only change the look. mark highlights, small is for side notes, u is an unarticulated annotation and s is no longer accurate.

Edits use del for removed text and ins for added text. Water is H2O and area is m2.
A <br> just forced this line break.

HTML is an abbreviation with a title. A definition uses dfn. This page was written on 11 November 2026, and not found carries a machine-readable value.

The rule above is an <hr>, a thematic break between paragraphs.

Direction, ruby and breaks

<bdo dir="rtl"> reverses text: left to right.

<bdi> isolates a name of unknown direction: user إيان scored 90 points.

    What is in this page's head

    ElementWhat it does here
    <meta charset>Declares UTF-8 so every character on the page decodes correctly.
    <meta name="viewport">Makes the layout follow the device width on phones.
    <title>The text on the browser tab.
    <meta name="description">A summary for search results and link previews.
    <meta name="robots">Set to noindex, because this is a temporary test page.
    <meta name="theme-color">Colours the browser toolbar on mobile to match the page.
    <link rel="icon">The tab icon, an inline SVG so no extra file is needed.
    <link rel="stylesheet">Loads the three fonts from Google Fonts.
    <style>All of the page's CSS.
